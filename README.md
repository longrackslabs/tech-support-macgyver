# Tech Support MacGyver

Workshop rescues, repairs, and unlikely uses for old hardware. Inspired by [r/techsupportmacgyver](https://www.reddit.com/r/techsupportmacgyver/).

Each project gets its own folder with hardware details, what we tried, what worked, and enough recovery notes to pick it up again later.

| Project | Status |
| --- | --- |
| [Peloton tablet](peloton-tablet/) | Broken-touchscreen tablet repurposed for Home Assistant, browser access, and Spotify control. |
| [Touch nightlight](touch-nightlight/) | Project folder reserved; notes to be added. |
| [Bose SoundLink](bose-soundlink/) | Project folder reserved; notes to be added. |

Document observed results separately from assumptions and untested ideas. Keep credentials, personal screenshots, raw device dumps, and downloaded installers out of this repository.
